# 👗 بوت متجر عبايات
### ثناء | thanaa.codes

بوت يستقبل طلبات العبايات من الزبونات، يختارون نوع العباية والمقاس واللون، ويحسب لهم الاجمالي مع الشحن تلقائياً.

## ✨ وش يسوي؟
- يعرض 5 انواع عبايات: كلاسيك، مطرزة، يومية، مناسبات، ملونة
- يخلي الزبونة تختار المقاس: من S الى XXL
- يخليها تختار اللون: اسود، كحلي، بيج، رمادي، بني
- يحسب الاجمالي حسب العدد
- يضيف سعر الشحن: استلام مجاني، داخل المدينة 20 ريال، خارجها 35 ريال
- يستلم اسم الزبونة ورقمها وعنوانها

## 🚀 كيف تشغليه؟
python abaya-shop-bot.py

## 💰 السعر
2500 ريال سعودي - نسخة كاملة لمتاجر العبايات

## 📦 مثال على الطلب
العباية: عباية مطرزة
المقاس: M
اللون: اسود
العدد: 1
الشحن: توصيل داخل المدينة
الاجمالي: 370 ريال
